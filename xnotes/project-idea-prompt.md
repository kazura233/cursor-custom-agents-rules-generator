在此处起草你的项目初始提示或想法。使用这个来在使用敏捷工作流时（在 docs/agile-readme.md 中记录）启动项目。在初始 PRD 起草后，与 cursor 中的 LLM 或外部 LLM 一起工作，提出问题，让 LLM 向你提问等，以真正定义一个充分的 PRD 和故事列表。然后继续生成架构文档，以确保项目以易于维护和扩展的方式构建，同时明确指定你想要使用的技术和库。这还将帮助你确定你可能想要初始生成哪些规则来帮助你构建项目。

示例：

让我们构建一个 NextJs 15 Web 应用程序来跟踪我们的月收入和支出。我想要一个使用 Tailwind CSS 和 shadcn 组件创建的现代 UI，在 Supabase 中安全存储，以及一个现代 API。我还希望它通过 Facebook 或 Google 集成社交登录。它还需要是移动友好的，这样我可以快速输入支出，并在需要时访问所有信息。我设想如果我还未认证，会有一个登录页面，一旦认证后，主页面会显示我的总账户余额减去支出，以及最近 5 笔收入和支出条目。我希望从页面有一个非常快速的移动友好方式来输入快速支出或收入，至少包括金额和描述。所有条目都应该自动安全保存。如果超过 5 分钟不活动，我应该自动登出。

{ 驱动初始 PRD 草稿的细节越多越好！但是，你不必一开始就考虑所有事情，先完成 PRD 草稿，然后使用 AI 作为 PRD 专家进行交流，然后作为架构专家进一步充实细节！如果你对某些方面不太在意，也要开放让 AI 专家建议库和技术选择。有些应用程序可能更适合你最熟悉的那一个，这也可以帮助你接触和学习新技术。考虑使用更深入的网络研究，这样你就不会受到所选 LLM 内部知识截止日期的限制，你可以通过 MCP 启用这一点来扩展 LLM 能力，使用 Perplexity、Tavily 或基本网络搜索，以确保你将使用最新最好的可用模型和库。如果要在 Cursor 中这样做，也建议选择 Sonnet 或 Deepseek Thinking Agent 模式，或使用支持深度思考的 mcp 插件。 }
